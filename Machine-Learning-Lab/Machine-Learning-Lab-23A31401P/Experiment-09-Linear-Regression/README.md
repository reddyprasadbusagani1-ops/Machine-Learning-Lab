# Experiment 9: Simple Linear Regression

## Aim
To fit a simple linear regression model and evaluate predictions for a continuous target.

## Theory
Simple linear regression models the relationship between one independent variable and a numeric target with a straight line. This experiment uses a small synthetic illustrative dataset, not collected student data.

## Algorithm
1. Generate reproducible illustrative data.\n2. Split into training and test sets.\n3. Fit LinearRegression.\n4. Print slope, intercept, MSE, and R².\n5. Plot observations and the fitted line.

## Program
Run `main.py` from the repository root:

```cmd
python Experiment-09-Linear-Regression/main.py
```

## Requirements
Install packages from the root `requirements.txt` first.

## Result
The program prints relevant statistics or evaluation metrics. For experiments that create plots, a plot window is displayed and the plot is saved as `plot.png` in the experiment folder.
