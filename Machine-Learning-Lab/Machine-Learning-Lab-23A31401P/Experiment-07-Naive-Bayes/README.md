# Experiment 7: Naïve Bayes Classification

## Aim
To classify observations using the Gaussian Naïve Bayes algorithm.

## Theory
Naïve Bayes applies Bayes' theorem and assumes features are conditionally independent given the class. GaussianNB models continuous features with class-conditional Gaussian distributions.

## Algorithm
1. Load the Iris dataset.\n2. Split into training and test sets.\n3. Fit Gaussian Naïve Bayes.\n4. Predict and evaluate using accuracy, confusion matrix, and classification report.

## Program
Run `main.py` from the repository root:

```cmd
python Experiment-07-Naive-Bayes/main.py
```

## Requirements
Install packages from the root `requirements.txt` first.

## Result
The program prints relevant statistics or evaluation metrics. For experiments that create plots, a plot window is displayed and the plot is saved as `plot.png` in the experiment folder.
