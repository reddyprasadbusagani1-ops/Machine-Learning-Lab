# Experiment 8: Support Vector Machine Classification

## Aim
To apply an SVM classifier to a binary classification dataset.

## Theory
An SVM finds a separating boundary with a large margin. The RBF kernel can represent nonlinear boundaries. Standardizing features is important for SVM performance.

## Algorithm
1. Load the Breast Cancer Wisconsin dataset.\n2. Split the dataset.\n3. Standardize features and fit an RBF-kernel SVM.\n4. Evaluate using accuracy and a classification report.

## Program
Run `main.py` from the repository root:

```cmd
python Experiment-08-SVM-Classification/main.py
```

## Requirements
Install packages from the root `requirements.txt` first.

## Result
The program prints relevant statistics or evaluation metrics. For experiments that create plots, a plot window is displayed and the plot is saved as `plot.png` in the experiment folder.
