# Experiment 5: Decision Tree Regression

## Aim
To predict a continuous target using a decision tree regressor.

## Theory
A decision tree regressor partitions feature space into regions and predicts a numeric value in each leaf. Limiting tree depth helps control model complexity.

## Algorithm
1. Load the diabetes regression dataset.\n2. Split it into training and test sets.\n3. Fit a decision tree regressor.\n4. Predict target values and calculate MAE, MSE, and R².

## Program
Run `main.py` from the repository root:

```cmd
python Experiment-05-Decision-Tree-Regression/main.py
```

## Requirements
Install packages from the root `requirements.txt` first.

## Result
The program prints relevant statistics or evaluation metrics. For experiments that create plots, a plot window is displayed and the plot is saved as `plot.png` in the experiment folder.
