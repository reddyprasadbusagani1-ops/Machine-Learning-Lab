# Experiment 10: Logistic Regression Classification

## Aim
To use logistic regression for a binary classification problem.

## Theory
Logistic regression estimates class probabilities using a logistic function. A classification threshold converts probabilities into predicted class labels. Scaling often helps optimization converge.

## Algorithm
1. Load the breast cancer dataset.\n2. Split into train/test data.\n3. Scale features and fit logistic regression.\n4. Evaluate with accuracy, confusion matrix, and classification report.

## Program
Run `main.py` from the repository root:

```cmd
python Experiment-10-Logistic-Regression/main.py
```

## Requirements
Install packages from the root `requirements.txt` first.

## Result
The program prints relevant statistics or evaluation metrics. For experiments that create plots, a plot window is displayed and the plot is saved as `plot.png` in the experiment folder.
