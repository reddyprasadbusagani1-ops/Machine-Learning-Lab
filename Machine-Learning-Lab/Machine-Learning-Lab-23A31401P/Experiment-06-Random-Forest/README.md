# Experiment 6: Random Forest Classification and Regression

## Aim
To apply Random Forest algorithms to classification and regression datasets.

## Theory
Random Forest trains many decision trees on bootstrapped samples and combines their predictions. Classification uses voting; regression averages numeric predictions.

## Algorithm
1. Train a Random Forest classifier on Iris data.\n2. Evaluate classification accuracy.\n3. Train a Random Forest regressor on diabetes data.\n4. Evaluate MSE and R².

## Program
Run `main.py` from the repository root:

```cmd
python Experiment-06-Random-Forest/main.py
```

## Requirements
Install packages from the root `requirements.txt` first.

## Result
The program prints relevant statistics or evaluation metrics. For experiments that create plots, a plot window is displayed and the plot is saved as `plot.png` in the experiment folder.
