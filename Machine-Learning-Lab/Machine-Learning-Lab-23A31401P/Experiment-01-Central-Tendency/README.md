# Experiment 1: Central Tendency and Dispersion

## Aim
To compute mean, median, mode, variance, and standard deviation for a dataset.

## Theory
Central tendency describes the typical value of data. Dispersion measures how spread out the values are. This program uses Python's `statistics` module and reports sample variance and sample standard deviation.

## Algorithm
1. Store numeric observations in a list.\n2. Compute mean, median, and mode.\n3. Compute sample variance and sample standard deviation.\n4. Display the results.

## Program
Run `main.py` from the repository root:

```cmd
python Experiment-01-Central-Tendency/main.py
```

## Requirements
Install packages from the root `requirements.txt` first.

## Result
The program prints relevant statistics or evaluation metrics. For experiments that create plots, a plot window is displayed and the plot is saved as `plot.png` in the experiment folder.
