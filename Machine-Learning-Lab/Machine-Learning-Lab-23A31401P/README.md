## Overview
This repository contains runnable programs for the 14 experiments in the supplied syllabus. Most experiments use scikit-learn and standard Python data handling. The programs use small, reproducible built-in datasets so they can be run without downloading dataset files.

## Experiments
1. Central tendency and dispersion
2. Pre-processing: attribute selection, missing values, discretization, outliers
3. KNN classification and regression
4. Decision tree classification with parameter tuning
5. Decision tree regression
6. Random forest classification and regression
7. Naïve Bayes classification
8. Support Vector Machine classification
9. Simple linear regression
10. Logistic regression classification
11. Multi-layer Perceptron classification
12. K-means clustering and testing different K values
13. Fuzzy C-Means clustering
14. Expectation-Maximization based clustering using Gaussian Mixture Models

## Requirements
- Python 3.10 or newer
- Windows 10/11, macOS, or Linux
- Internet access only to install packages

## Install dependencies on Windows
Open Command Prompt in the extracted project folder and run:

```cmd
py -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If `py` is not recognized, use `python` instead.

## Run an experiment
For example:

```cmd
python Experiment-01-Central-Tendency/main.py
```

Run any experiment from the project root using its relative path. Each experiment folder includes a README with aim, theory, algorithm, program, and run command.

## Notes
- Built-in datasets are used to keep the programs reproducible and easy to run.
