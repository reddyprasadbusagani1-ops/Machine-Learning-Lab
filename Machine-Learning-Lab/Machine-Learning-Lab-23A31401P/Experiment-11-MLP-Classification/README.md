# Experiment 11: Multi-layer Perceptron Classification

## Aim
To classify data using a Multi-layer Perceptron neural network.

## Theory
An MLP is a feed-forward neural network containing input, hidden, and output layers. It learns weights using backpropagation. Feature scaling is important for stable training.

## Algorithm
1. Load the Iris dataset.\n2. Split into training and test sets.\n3. Scale the features and fit an MLP with two hidden layers.\n4. Evaluate accuracy and the classification report.

## Program
Run `main.py` from the repository root:

```cmd
python Experiment-11-MLP-Classification/main.py
```

## Requirements
Install packages from the root `requirements.txt` first.

## Result
The program prints relevant statistics or evaluation metrics. For experiments that create plots, a plot window is displayed and the plot is saved as `plot.png` in the experiment folder.
